# Portfólio — Ítalo Gabriel

Portfólio pessoal desenvolvido para apresentar meus estudos, projetos e conhecimentos na área de tecnologia. O site tem uma identidade visual escura, inspirada em atmosferas góticas e noir, com detalhes em verde e dourado.

🔗 **Acesse o site:** https://biel9080.github.io/Portifolio/

## Sobre o projeto

Este projeto foi desenvolvido como parte da minha avaliação acadêmica e também como uma forma de reunir meus trabalhos em um só lugar. A página apresenta uma breve introdução, tecnologias que venho estudando, alguns projetos e formas de contato.

## Funcionalidades

- Navegação entre as seções da página.
- Apresentação pessoal e lista de tecnologias.
- Cartões com links para projetos no GitHub.
- Música ambiente com botão para reproduzir e pausar.
- Layout adaptável para telas menores.
- Animações discretas ao rolar a página.

## Tecnologias utilizadas

- **HTML5** — estrutura e conteúdo.
- **CSS3** — layout, identidade visual, efeitos e responsividade.
- **JavaScript** — controle da música e animações de entrada.
- **Git e GitHub** — versionamento e hospedagem.
- **GitHub Pages** — publicação do site.

## Projetos apresentados

- **AI Recipe Assistant:** gerador de receitas com Python, LangChain e API da Groq.
- **Student Management System:** projeto em Python para praticar lógica de programação e organização de dados escolares.
- **SQL Database Practice:** exercícios de criação e relacionamento de tabelas e consultas SQL com MySQL.

## Como executar localmente

1. Faça o clone do repositório:

   ```bash
   git clone https://github.com/Biel9080/Portifolio.git
   ```

2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` com a extensão **Live Server** ou abra o arquivo diretamente no navegador.

Mantenha a pasta `assets` no mesmo nível de `index.html` para que a imagem e o áudio sejam encontrados corretamente.
